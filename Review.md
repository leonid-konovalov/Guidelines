### Document structure

* Maintain a clear document structure.
* For a quick start, copy the structure of a similar review, but not the
  content.
* Summarize the objectives at the beginning of a section.

  ```
  % Good:
  \section{Verification of model implementation}
    
    In this section we verify the model implementation. We found no issues. 
  ```

* Place detailed proofs in the Appendix.

### Content

* Write the document content from scratch.
* Do not copy and modify another source.
* Avoid using a language model to generate the content.
* Be ready to explain every single word you wrote.

### Writing style

* Avoid wordiness:
    * Be concise;
    * Be specific;
    * Remove any sentence not contributing to the section objectives.

* Split long or difficult sentences into shorter ones.

### Accuracy

* Maintain domain-expert-level accuracy.

* Pay attention to detail.

* Use one term for each concept.
  ```
  % Wrong:
  Let $c_t$ be the coupon paid by the product.
  % A bit later
  By $A_t$ denote the accumulated dividend $\int_0^t c_u du$. 
  ```

* Avoid any statements that contradict each other.
  ``` 
  % Wrong:
  We assume that $Y_i = \beta X_i + \varepsilon_i$, where 
  $\varepsilon_1, \varepsilon_2, \ldots $ are independent.   
  % A bit later 
  Let $\rho$ be the correlation between $varepsilon_i$ and 
  $varepsilon_{i+1}$. 
  ```

* Where possible, avoid repeating content from other sourcest and use a
  reference.
  ``` 
  % Correct:
  % Instead of a long proof
  If two measures agree on a $\pi$-system $\CCC$, they also agree on the 
  $\sigma$-algebra generated by $\CCC$. See \cite{Bil95} for a proof.
  ```

* Use correct English.
    * If needed, ask a language model to highlight possible language errors,
      but not to rephrase the text.
    * Fix errors manually only when you agree with the model. Do not copy and
      paste the corrected text.

###### Rationale

A language model is good at English, not at mathematics. After rephrasing, the
text becomes blurry and makes less sense.

### Notations

* Use consistent notations throughout the document.
  ```
  % Wrong:
  Let $S_t$ be the underlying price. 
  % A bit later
  We have $S(t) = \mu(t) dt + ...$
  ```

* Introduce every symbol before or right after using it.
  ```
  % Correct:
  Let $S$ be the underlying price. Assume that
  ...
  \begin{equation*}
    S_t = \mu S_t dt + \sigma S_t dW_t,
  \begin{equation*}
  where
  \begin{itemize}
    \item $\mu$ and $\sigma$ are positive parameters,
    \item $W$ is a Brownian motion.
  \end{itemize}
  ```

* Use one symbol for each object throughout the document.
